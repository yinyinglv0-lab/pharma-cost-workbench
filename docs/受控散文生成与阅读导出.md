# 受控散文生成与阅读导出

## 范围与当前状态

本文是源码包可携带的通用运行说明，不包含真实企业数值、原文摘录、私人附件路径或私有审计回执。它描述当前代码中的受控散文合同与制造业阅读副本，不是最终验收或公开发布授权。

相关源码为 `enterprise/prose_contract.py`、`enterprise/prose_validation.py`、共享 `analysis_contract.py` / `analysis_narrative.py`、`enterprise/manufacturing_report.py`，以及现有模型、报告、页面和服务集成。主任务的最终集成验收、五次一致性/稳定性核查、独立人工质量评分和第三机部署仍待完成；不得把离线合成断言或导出函数存在称为这些事项已通过。

## 1. 新旧模型合同隔离

新合同版本为 `bound-numeric-prose/1`。只有服务端在实际分析上下文顶层设置准确的 `prose_mode` 值才启用；浏览器补充文字、知识内容或嵌套对象中的同名文字不构成开关。旧无标记上下文仍按原有正文禁数合同校验，不删除旧守卫，也不据当前配置改写历史模型结果。

模型继续返回内部 JSON 传输对象：根字段 `elements`，完整包含材料、人工、制费。

| 分析 | 每个要素的字段 |
| --- | --- |
| 归因 | `hypothesis`、`recommendation`、`evidence_ids` |
| 对标 | 上述字段以及 `claim_type`、`missing_evidence` |

JSON 用于严格字段、引用、诊断及回放，不作为面向业务读者的输出格式。页面和阅读稿展示散文、建议与程序生成的脚注；不让模型自造 HTML、Markdown、标题、枚举或脚注编号。缺失、额外字段及未经允许的分支仍由现有合同拒绝。

当前受控散文提示词采用 `1.4-bound-numeric-compact` 版本，上下文另记 `contextual-narrative/1.4`，输出schema仍为 `bound-numeric-prose/1`。M2将重点对象的市场参考变化与条件式价/量核查绑定为整句，主要/次要会计来源不冒充业务根因；仅相邻可比月/季使用环比。工时固定时明确机械分摊，不由比率推断岗位效率。M3拆结构完整列数，拆原因以单位差和贡献度为锚；完整结构句为可选，不再强制全文重复。机制句须与当前焦点相关；不借无关能源知识解释折旧。完整合成示例展示三要素、实际类型的知识来源、未知原始凭证库存、来源去重并集，以及不使用无关可选参考句；不会把所有可用数字机械复述。归因合同的有限行情窗口优先保留当前核算重点对象的已获准行情，仍不把参考价当结算实价。调用前仅对重复输入做无损去重：重复授权句指向同一完整合同，共同指令放入 `task_defaults`，完全一致的来源描述放入 `reference_registry` 并保留逐要素引用顺序。同ID但不同描述不合并。`reconstruct_provider_context()` 可精确还原完整上下文；校验器始终使用未压缩的原上下文。它不删事实、引文、证据范围或建议可用性，不压缩或修补模型候选。原请求摘要对应实际传给provider的投影；新旧指令版本分别记录。

## 2. 数字只能来自完整绑定句

服务端用同一确定性分析叙述生成 `prose_contract`，按要素给出有界 `statements`。每句绑定事实角色、主体、指标、期间、单位、方向和来源 ID；标记为 `required` 的句子必须完整保留。

模型可选择获准的可选句并调整完整句顺序，但不能拆出数字重新组句、套用另一工厂或指标、换单位、改正负号、计算、舍入或引用示例数字。其他上下文数值供理解，不是正文数字权限。所有采用句绑定的基期、当期、对方或参考来源均须保留在该要素的 `evidence_ids`。

允许模型在完整事实句之间组织无数字限定性解释，但仍须保留待核查语气和实际证据边界。建议和缺口字段不复制数值句、不写数字或编号；标题、序号和脚注由渲染器生成。字数目标是软约束，不为压缩到固定长度而截断必要事实或限定语。

严格校验覆盖未授权数词、百分号、运算符、编码标识、Unicode 数字及不完整/否定/更换主体的拼接。原始候选不被自动修补；临时移除获准完整句的残余视图只用于校验，不能替换审计原文。

## 3. 引用数字并不放松因果与行动要求

`prose_validation.py` 在完整句与引用校验之外，继续调用既有因果、观察一致性、知识机制、行动可用性和字段形状校验。

- 会计差额、产量桥接和同产量标准化对比不等于已实现节约、效率优势或实际业务原因。
- 市场或行业参考 ID 只支持其获准完整参考句，不能替代机制文档引用或冒充本企业实际量价。
- 配方/BOM、工序和设备知识描述参考关系，不确认本期投料、故障、停机或质量事件。实际量价缺失仍不可用，不由参考数据插补。
- 保留反向抵消与负贡献；基期或净变化为零时，相应比率保持无定义，不能强行凑整。
- 建议必须有明确责任角色、已有数据或获准请求凭证类别、核对动作及交付物。请求凭证不等于已经取得；不得臆造凭证，也不得以未取得外部资料阻断当前已有核算分析。
- 对标方缺失明细只列证据缺口，不推断其采购、工艺或管理事实。产品级与公司级口径不能混用。

模型失败时保留结构化 `rule_id / field / offending / expected` 诊断及原候选。每个允许修正的模型生成阶段至多首次请求加一次受预算约束修正；不是无限重试，也不是整个工作流只有两次调用。某些服务分支会进一步关闭修正，真实调用数以 `model_calls` 与 attempts 为准。再次失败或超时则明确降级，不能把确定性文本称作模型已成功采用。

未选择新注册模型时，新版受控散文的可终止工作进程总预算仍为95秒、旧合同45秒，单次provider仍不超过40秒或更小的服务端配置。明确选用受控注册项时，使用该项的每次时限（1至120秒），阶段预算为 `min(255, 2 × 时限 + 15)`；例如80秒对应175秒，仍受剩余预算限制。**所有分支最多两次，网络失败不重试、不换模型。**父进程与worker核对被冻结的安全配置身份；浏览器参数、嵌套文字或任意budget字段不能提高时限。JSON响应、并发及显式云端授权要求不变，提供方固定请求选项也纳入摘要；预算不是成功率或时延保证。注册与密钥边界见 `docs/任务级模型配置.md`。

## 4. 页面与旧报告读取

已校验散文在主要阅读区只呈现一次，完整保留其文本和经批准建议；确定性事实、桥接、证据缺口和模型审计保留在审计区域。建议标签的蓝色、强调及左边线由 UI/文档渲染器控制，不依赖模型插入样式。所有模型/来源文本仍须转义；长文本不可通过截断丢失证据边界。

旧制药报告通过 `report/narrative_adapter.py` 使用完整期间的共享事实/叙述，不能把季度偷换为期末月；历史冻结结果和原制药报表仍有自身契约。这不表示原应用全部标题、页面和旧模板已通用化。制造业新入口仍是“制造业配置与分析”。

## 5. 制造业冻结阅读副本

`ManufacturingService.export_report()` 在导出前调用 `get_run()`，验证冻结分析内容摘要、当前数据/报告权限及知识引用权限；渲染结束再次调用 `get_run()`，防止期间撤权后返回内容。导出不重新查询事实、不重新检索、不调用模型、不重新选择当前领域或旧模板。

HTTP 入口：

```text
GET /api/manufacturing/runs/{run_id}/export/docx
GET /api/manufacturing/runs/{run_id}/export/pdf
```

同一冻结分析也可从现有授权 run API 读取 JSON。制造业页提供“准备Word与PDF阅读副本”，显式生成后下载。服务只接受规定格式，不接受导出文件路径、模板路径或调用者自选字体路径。

| 输出 | 用途与边界 |
| --- | --- |
| 冻结 JSON | 完整审计依据，含范围、配置、数值、引用、模型/检索回执与版本摘要 |
| DOCX | 原生可编辑阅读副本，保留标题、正文、表格、引用目录与页码；编辑不改写原冻结 JSON，也不形成批准记录 |
| PDF | 可检索文字阅读副本，使用部署受控的 CJK 字体并保留来源目录；不是图片截屏或签发文件 |

导出器验证冻结行业配置与所选产品/规格/工厂/月份/计量，拒绝跨范围、篡改或不完整快照。仅允许读取部署控制的字体资源；输出中的来源文件名用于显示，不用于打开原始数据。缺少所需字体或字形时明确失败，不自动下载权重/字体或悄悄替换不可读字体。字体准备参照既有部署手册；源码包本身不携带本地字体或模型权重。

阅读副本保留 `needs_human_review` 与未签发状态，不是签章、合规结论、模型质量认证或任务批准。五行业共用通用冻结阅读稿，不将制造业字段伪装成旧制药工厂/盒单位；也不据此声称旧制药所有模板和报告管理环节均完成跨行业迁移。

## 6. 离线验证与分发规则

公开 portable 测试包括散文纯合同、模拟运行投影与模型替身集成、UI 安全显示，以及五组公开 SIMULATION 的临时仓库 DOCX/PDF 导出检查。原始业务 CSV、私人审计报告和真实模型/外部业务系统验收脚本不因此进入源码包；依赖原业务文件的报告测试继续排除。导出测试还需部署环境中已存在受支持的 CJK 字体。

示例、模型替身与模拟知识发布只能说明相应离线边界。实际模型五次一致性/稳定性、完整真实业务联合回归、导出视觉逐页审核、人工评分、真实任务发送与第三机运行必须分别留证；此说明不宣布这些验收完成。主任务 GO 前不生成最终交付包，历史包保持不可变。
