# 演示视频讲稿（5 分钟内）

> 端到端流程：选择分析条件 → 生成报告 → 看板展示 → 对标分析 → 发送 RPA 任务
> 建议：屏幕录制 + 配音；总时长约 4 分 40 秒，留 20 秒片尾信息。

## 分镜总览

| # | 环节 | 时长 | 屏幕画面 |
|---|---|---|---|
| 0 | 开场 | 30s | 系统首页+架构一句话 |
| 1 | 选择分析条件 | 40s | 工作台首页选择产品/规格/月份 |
| 2 | 生成归因分析（看板） | 60s | 成本看板页：趋势/瀑布/结构→点击"生成归因分析" |
| 3 | 生成报告 | 60s | 报告中心：生成月度报告→预览→导出 PDF |
| 4 | 对标分析 | 60s | 对标页：差异表→拆结构→生成跨厂原因分析 |
| 5 | 发送 RPA 任务 | 60s | 任务页：建议→创建任务→审核→签发→mock 回执 |
| 6 | 收尾 | 10s | 总结+仓库地址 |

## 逐段台词

### 0｜开场（30s）
"大家好，这是我们团队实现的《基于 RAG 与大模型的制药企业产品成本智能分析报告系统》。
它覆盖赛题要求的四大模块：智能报告生成、成本看板与归因、对标三步法、RPA 整改闭环。
接下来用一条完整业务流演示：从选择分析条件，到生成报告、看板展示、对标分析，最后自动发送整改任务。"
（画面：系统首页，鼠标划过四个模块入口）

### 1｜选择分析条件（40s）
"第一步，选择分析条件。这里选择分析主题——月度成本分析，目标产品——银黄口服液，规格 10ml×10支/盒，
分析月份——2026 年 5 月。系统会读取已授权的成本汇总与明细数据。"
（操作：依次点选三个下拉框）
"注意底部状态：混合检索已就绪——说明本地 BGE-M3 向量模型与已发布的法规、配方、工艺知识库都可用。"

### 2｜成本看板与归因分析（60s）
"进入成本看板。左侧是趋势图，展示近 6 个月三要素单位成本走势；中间是瀑布图，把 5 月总成本变动
+50,680 元分解为产量影响与单位成本影响；下方是本月成本结构环图。右上角还有产品×月份×要素热力图——加分项。
点击图表任意柱，系统会带着该月该要素的问题自动检索知识库并展示依据。"
（操作：点击材料柱→展示检索依据卡片）
"现在点击『生成归因分析』。系统先做向量+BM25 混合检索，然后主模型生成初稿，修正模型做一轮修订，
数字与引用全部通过合同校验。看，材料贡献度 67.09%，金银花单位消耗成本 3.35 变为 3.50 元，
系统引用了知识库原文——'提取收率每降 1 个百分点，材料成本上升 0.08 元每盒'，并给出核查建议。
关键设计：所有数字由程序计算渲染，模型只写有边界的解释，防止编造。"

### 3｜生成报告（60s）
"接下来到报告中心，一键生成 5 月月度成本分析报告。报告按模板五章节组织：封面与基本信息、
总成本概览、成本要素明细、重点产品专项分析、总结与建议。生成后可在线预览，也可导出 PDF 或 Word。
注意报告里的引用卡片——每句模型解释都有来源文档、页码和版本号可点开核对。"
（操作：生成→预览→导出 PDF，打开 PDF 展示排版）

### 4｜对标分析（60s）
"进入对标分析，系统对中药一厂和中药二厂执行三步法。第一步找差异：差异总览表展示三要素的
差异金额与差异率，一厂材料高 0.01 元、人工低 0.20 元、制费高 0.12 元。第二步拆结构：
差异结构树可下钻到原材料明细。第三步拆原因：点击『生成跨厂原因分析』，模型结合知识库给出
归因文本与改进建议——注意它严格遵守边界，不编造二厂没有提供的分项数据。
这里还有行业三方对标：一厂、二厂分别对照行业 P25/P50/P75 的位置，并展示原文件的对标评价列。"
（操作：三个 Tab 依次点开；展示行业参考表与一厂问题小结）

### 5｜发送 RPA 任务（60s）
"最后是整改闭环。把对标建议一键转为整改任务：任务包含标题、责任人、部门、优先级、截止时间，
主管审核后签发。系统通过 HTTP API 把任务发送到官方模拟 RPA 服务，回执显示——
『模拟微信：已发送至 张伟(采购部)』，任务状态可从 sent 推进到 confirmed。
责任人提交整改材料、独立人员验收后任务关闭；关闭时系统还会自动把这条异常处理记录
生成知识库候选，经管理员确认后进入『企业内部知识·异常处理记录』板块，形成真正的数据闭环。"
（操作：创建任务→审核→签发→展示回执与状态→任务页看板）

### 6｜收尾（10s）
"以上就是四大模块的完整闭环演示。完整代码与技术方案文档已托管在 GitHub 公开仓库
yinyinglv0-lab/pharma-cost-workbench，欢迎查看。谢谢！"

## 录制提示

- 数据口径：67.09/12.31/20.60% 三个贡献度数字是系统校验基准，建议在归因页口头强调一次
- 若界面出现"混合检索正在预热"，等待就绪后再进入第 2 步（约 1 分钟，讲稿可补一句"模型正在预热"）
- 全程窗口保持中文界面；导出 PDF 前确认系统已装中文字体（本地 start.bat 环境自动处理）
- 备用讲法（若时间紧张）：第 3 步报告导出可只展示预览页，把 PDF 打开放到片尾彩蛋
