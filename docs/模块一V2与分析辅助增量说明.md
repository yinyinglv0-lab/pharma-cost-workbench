# 模块一 V2 与分析辅助增量说明

本说明对应 2026-09-20 的增量实现。原交付 README、技术/用户/部署文档和原公开源码版本保留，本文说明后续实现差异。源码包仅包含白名单代码与文档，业务数据、模型凭证、向量索引、报告和评测输出另行保留于私有目录；本次没有重新公开发布。

## 模块一：事实、知识与动作的同一条证据链

报告使用 `report-payload/2.0`；仍可校验和重放已冻结的 v1 报告。金额、贡献度、产量影响和单位成本影响由程序计算。明细区分金额变化最大的项目与单位成本影响最大的项目，并保留“单位消耗成本不是采购价、市场价不是实际采购价、减产支出下降不是节约”等口径。

知识检索先取得已授权成本事实，再按材料、人工、制造费用和实际对象发起查询。正式路径仍为 LangChain `ControlledKnowledgeRetriever` → `ControlledSearchEngine`：本地 BGE 向量、BM25、词项图与 RRF；不把词项图称为经营因果图，也没有新增 reranker。新知识代际采用按产品章节切分和适用性元数据，保留原文、页范围、版本与字符位置；检索、适用、选入、引用、语义支持分别记录。向量超时会如实记录降级，不能把“没有引用”自动解释为“库里没有资料”。

模型采用 `report-claims/2.0` 和 `report-evidence-actions/2.6`。输入只包含本次解释需要的事实编号、明确机制、按要素选定的原文引句和具体核查清单。模型只组织待核查机制与建议，数字及工艺标准由程序呈现。校验覆盖真实编号、要素/范围、一个机制句、数字边界、实际耗用反推、明确工序与所展示引句的对应关系；不通过则使用同样经过合同校验的规则卡。词项和结构规则不等于完整语义证明，专业审核状态始终独立。

单厂与跨厂解释分别生成并记状态，在同一次冻结之前进入报告。季度跨厂差额逐月按“同品同规格两厂单位差 × 当月本厂产量”计算后求和，不以季末月替代整季。缺少对方明细时只说明会计差异和后续配对资料需求。

建议包括实际对象、责任部门、凭证、交付物、完成判据和完整分析期间；跨厂核查明确两厂同口径经营凭证，折旧对象使用资产卡片、期间计提底稿和分配基数。整改草稿保留这些要求，模型补充不能抹掉原分析要求。对接既有官方任务格式时，完整期间进入 finding，原 analysis_month 仍为锚点月。

真实模板共 23 个业务节点（6 主章、15 二级、2 三级）。验证器检查标题、顺序、父级、有效正文、必要表格、占位符和同源内容。PDF 仅声明可抽取内容及顺序可验证，不声称 PDF 含 Word 的标题层级属性。3 场景 × 2 格式 × 23 节的 138 只是内部覆盖计数，不是赛题官方评分公式。

## 成本预测基线

页面“分析辅助 → 成本预测基线”，接口 `POST /api/forecast`。输入为工厂、产品、规格、截止月和方法；服务端同时检查 `analysis.generate` 与 `data.read` 范围，并使用一次已授权数据版本。

- `naive`：下一月各要素延续截止月；默认方法。
- `ma3`：下一月各要素取最近三个连续月均值。
- 只支持一步预测；三要素程序求和得到单位成本。未来产量未知，因此没有总成本预测。
- 训练只使用截止月所在的连续日历段，不跨缺月、不插补、不假定已有连续十二个月。
- 候选方法在相同滚动检验月份比较 MAE、RMSE、MAPE；每个检验月只使用此前数据。实际值为零时 MAPE 留空。
- 这是当前版本数据的回溯时间切分，不是假称当时留存快照的在线回测。不自动按同批误差选“最佳方法”。
- 没有校准预测区间：少于五个共同残差时为 `insufficient_calibration`，更多时仍为 `not_calibrated`；上下界及覆盖率为空。

结果 `cost-forecast/1.0` 包括训练月、实际采用月、断档、逐折输入与误差、精确算术表示、数据版本/哈希和训练哈希。切换权限或数据版本后，页面不复用失效的结果。

## 受控分析助手

页面“分析辅助 → 分析助手”，接口 `POST /api/agent/query`。它是规则意图路由器，支持自然语言短句和明确的页面选择范围；不宣称拥有任意自主工具能力。每次请求从原始消息和本次授权目录重新规划，在执行处再次检查身份及权限，不能提交工具名、伪造计划或身份来改变服务端分派。

| 操作 | 行为 |
|---|---|
| 成本汇总 | 查询唯一同厂、同品、同规格、同月真实记录 |
| 归因 | 调用既有一厂规则归因与授权检索，不请求云模型 |
| 对标 | 检查双厂权限并计算同口径会计差额 |
| 知识检索 | 受控检索已授权资料，文档内容仅作为数据 |
| 预测 | 调用同一预测服务 |
| 打开报告 | 导航至已有授权报告页 |
| 准备/预览报告草稿 | 校验并填入报告表单；不创建持久草稿 |

助手不批准、签发、发送、发布、删除、改数据或执行任意代码/SQL/URL。请求有歧义、范围冲突、多操作或缺数据时返回澄清状态。每次响应提供范围、操作轨迹、可用来源和无持久写入/无外发状态。用户在原报告页点击“生成并保存报告草稿”才调用既有创建流程。

## 验证与审核边界

新增单元、接口与 Streamlit 测试覆盖模板内容、引用位置、规则回退、完整期间、预测断档/泄漏/闭合和助手越权/计划伪造/无持久化预览。私有三场景评测记录真实模型调用、逐句引文、Word/PDF检查及 AI 辅助审查；历次被拒或存在错配的诊断批次均保留。

机器合同通过率、模型采用率、AI 辅助语义检查、图像边界检查及正式人工综合评分是不同证据。人工评分按用户决定保持待评；不由测试或模型代填，不建立虚构的官方及格线或权重。本增量只保存新报告草稿，没有自动审批、签发或发送，也未连接真实外部企业系统。
