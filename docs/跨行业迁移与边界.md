# 跨行业迁移与边界

## 结论与状态

第二轮已从单表适配器扩展为**声明式领域配置、五表完整快照、规范计算、受控知识接入、同源归因/对标、冻结分析与任务草稿**的代码路径。实际服务模块是 `enterprise/manufacturing_service.py`，不是 `manufacturing_application.py`。2026-09-24起，评委主工作台不再注册“制造业配置与分析”导航入口；底层服务、API、页面源码与历史实证保留。可迁移性在技术文档中展示，不挤占制药主界面。存在代码和模拟检查不等于真实行业部署；真实模型质量、独立人工及第三机验收仍须另行取得证据。

`config/manufacturing_examples/` 下制药、机械、汽车零部件、化工、电子五组均为 **SIMULATION**。每组九份源文件，共 45 份；另有一份公共 README。所有工厂、产品、数值、BOM、参考区间和知识正文均为模拟内容，不能称为真实行业数据、研究所得行业基准或五个实际部署。旧 `config/manufacturing_adapters/` 四份配置仍是未激活模板，不自动升级为这些样例。

操作步骤、CSV 表头、UI/API 和发布门控见 `docs/第二轮核查实施与运行说明.md`。本文说明复用边界，不替代财务口径、业务资料审核或访问授权。

## 2. 配置不是权限，也不是模型或文件执行规则

- 新运行路径要求 `manufacturing-domain/2` 与匹配的 `manufacturing-adapter/2`。不以降级到旧 schema 绕过新校验。
- 配置限定精确工厂、产品、规格、BOM 引用、工序/设备/指标引用、币种与单位。拒绝未知字段、重复 JSON 键、非有限常量、无效引用和不受支持的换算；不猜测别名或以“盒”冒充 kg/piece/tablet。
- 配置中不接受 Python/SQL 表达式、模型 endpoint、密钥、动态加载器、URL 工具、角色或权限覆盖。API 接收 JSON **原文字符串**后交给严格解析器，不先将重复键折叠成普通字典。
- 安装配置需要 `system.configure`，并检查配置内所有工厂和产品的数据访问范围。配置中的 `factories` 是数据范围，不是用户授权。安装不改变授权文件、不新增账户、不切换旧默认领域。
- 配置版本和数据版本使用显式期望版本；版本变化后须重新暂存/确认，不自动套用旧数据。原始来源与配置摘要证明完整性，不证明真实性或业务审批。

## 3. 五表完整覆盖与真实观测边界

完整快照恰好包含 `actual`、`budget`、`materials`、`labor`、`overhead`。实际与预算须覆盖**全部配置产品/规格 × home/peer 工厂 × 全部明确连续月份**；每条实际观察均需三类明细，材料明细覆盖该产品的显式 BOM。当前入口不是增量合并器；缺表、缺身份、重复身份、额外列、错期间或错单位时整批拒绝，不静默补齐。

数值以精确十进制文本进入，金额/产量/单位成本保留精确字符串。源成本与规范成本均要求 `material + labor + overhead = unitcost`、`unitcost × output = total` 精确闭合；明细金额也须精确闭合到实际要素金额。没有自动调平、容差或舍入修复。零产量、负调整、退货、联副产品分摊、在制品结转需要另行审定的会计政策，不能把当前输入限制误称为所有 ERP 场景均已支持。

材料实际数量与单位成对出现；有实际数量和采购单价时核对乘积。人工实际工时与时薪同样核对。**空白是不可用，不是零；不从 BOM、报价、金额/单价反推缺失实际领用量，不从人数与工作日臆造工时。**来源未给出良率时，`source_only` 良率指标保持不可用。数量/价格桥接、工时/费率桥接只在两期真实源字段均具备时计算。

总额、产量与单位成本桥接是可复算会计恒等式，不是确认后的生产原因。同规格跨厂单位成本差异不能单独证明效率、质量、设备、产能或工艺可比。比较始终保留原配置身份和 `measurement`，不经过旧制药中文表头重命名充当新行业事实。

## 4. 知识接入、发布与冻结图谱

知识流程是**原文暂存 → 人工核对并确认知识版本 → 在既有知识管理流程中受控发布混合索引**。制造业页确认返回 `catalog_only`，不是自动发布向量索引。机制资料逐产品登记，不能将多产品授权范围当成每个段落的内容适用范围。

新词表由已验证领域配置投影，随知识业务元数据、配置指纹与新发布冻结。检索不得用当前配置重建历史图谱。原有制药资料及已冻结的 graph V3 发布保持自身版本与哈希；新领域词表的 V4 路径不覆写旧发布。要产生图谱关系，仍需原文中的关系谓词、值及可定位证据，单有词表/BOM 绑定不等于本期发生了业务事件。

| 资料类型 | 可用角色与限制 |
| --- | --- |
| BOM、配方、工序、设备资料 | 适用且经审查的原文可解释机制；不能证明本期领用、停机、报废或采购实际发生 |
| 法规/质量/客户规范 | 必须核实有效版本和适用范围；摘要不自动等于法规原文或合规结论；制造业专用暂存类别并未覆盖所有监管工作流 |
| 市场价格 CSV | `market_reference`；保留材料、等级、报价单位、月份、来源，不能冒充本企业采购价 |
| 行业指标 CSV | `industry_reference` / `benchmark_reference`；保留类别、指标、单位、期间、分位数及来源，不能构造无来源“行业排名” |
| 成本观察基线 | 来自确认成本快照；只能支持数值观察，不能升级为机制证据 |

实际企业接入还须提供真实 BOM/图纸/工程版本、可用源表、业务凭证、工艺设备资料及有出处的参考信息。五组模拟知识中编造的参考区间只用于测试，不能补入真实行业事实。

## 5. 模型与任务必须分别批准

预览是确定性计算，不调用生成模型、不写分析记录、不建任务。生成并冻结分析是显式写操作；`use_llm` 默认 `false`。即使选择启用，也必须有获准的模型任务路由与数据出站设置，并满足已发布、未降级的受控混合检索。网关维持低温 `0.1`、JSON 响应和原有超时/并发/出站规则；业务 JSON 不提供调用权限。

实际调用 trace、校验诊断、引用和 `generation_status` 才能说明模型是否返回并被采用。模型不可用、检索不满足要求或输出被拒绝，必须标明，不把确定性文案称为已成功使用模型。数字由程序计算和绑定；新 `bound-numeric-prose/1` 分支只允许原样采用本要素完整授权事实句，不能取数字重组或计算，补充解释和建议仍受证据/因果/行动门控。旧无标记合同仍正文禁数。内部 JSON 不代替人读散文；代码接入和合成测试不等于模型质量评分。详见 `docs/受控散文生成与阅读导出.md`。

任务链保持：确认数据与可追溯引用 → 冻结分析 → 指定要素的任务草稿 → 人工补齐负责人/期限 → 既有提交、批准、签发、固定版本 outbox → 受限 RPA 发送与回执/审计。制造业服务只创建草稿，明确 `approved: false`、`sent: false`；不存在配置自动审批或自动发送。实际发送须另行授权，loopback/mock 回执只能称为模拟链路证据。

## 6. 分发与部署边界

源码构建器只读取字面白名单。旧 `REVIEWED_CONFIG_HASHES` 不变；45 份公开模拟源分别由 `REVIEWED_SIMULATION_HASHES` 的**原始字节 SHA-256**冻结。即使仍符合运行 schema，只要任一字节改变也要求重新分发审核。新增目录文件不因路径相近而入包；真实 CSV、私有配置、密钥、数据库、发布向量、本地权重仍不读取、不分发。

文字密钥/路径/大块内容扫描和既有资产摘要门禁继续执行；“SIMULATION”标签不是扫描豁免。manifest 对每个模拟文件声明分类和摘要，说明它们不是实际数据集。Docker 的 CSV 排除只对这 25 个已列明模拟 CSV 作窄例外，构建步骤重新核对全部 45 个文件摘要；不 COPY 本地权重。部署指纹增加明确公开样例和说明路径，但不会读取任意客户配置或环境值。

新包仅能写入尚无输出的目的地；既有源码包和清单不得覆盖。本轮主任务 GO 之前不生成最终交付包。本说明不证明容器构建或第三机运行已完成。
