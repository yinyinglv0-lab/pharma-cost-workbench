**组件职责**：
- `launch_system.py`：一键启动器（API + UI + worker + 可选官方 mock），端口自动选择、就绪探测、进程托管
- `enterprise_app.py`：Streamlit 主界面（受控导航、权限按 Principal 角色渲染）
- `backend_api.py`：HTTP API（报告/归因/对标/检索/任务，全部要求显式身份与授权）
- `enterprise/`：业务与治理层（金额口径、散文合同、RAG 发布代际、RPA 闭环）
- `managed/`：单实例 SQLite 状态库（审计 append-only 触发器、发布冻结不可改）

## 2. RAG 流程说明

### 2.1 入库管线（四段，上传≠生效）

```
① 上传/预览（零副作用）：preview_file() 解析正文+SHA256+覆盖度告警
② 暂存差异（stage）：写 pending 暂存行，生成 diff 与元数据变更摘要
③ 管理员确认（commit）：必填原因+勾选核对 → 写不可变 versions（校验正文/原件哈希与并发版本）
④ 构建并发布（publish）：分块→向量→建 index.sqlite→PRAGMA/哈希全量校验→同一事务切换 active_release 指针
   失败整单记 failed 且不切换；撤销(revoke)在检索前/编码后双重过滤，已撤销文档不得重发
```

- 支持格式：PDF / DOCX / TXT / CSV（≤20MB，.doc 拒绝并提示转 docx）
- 解析器：pypdf（文本层+图片覆盖检测）、python-docx（段落+表格）、csv(strict) 一行=一条逻辑记录
- **视觉增强解析**（多模态协作）：PDF 无文本页/图片页时，fitz 整页渲染→视觉模型（glm-4v-plus/kimi-k3）
  逐页理解→合并稿入 stage 差异预览→人工确认。视觉内容默认仅背景参考；显式选择机制依据才留痕
  `vision_reviewed` 解锁，原件始终保留原 PDF
- **自动归类**（多模态协作）：CSV schema > 文件名关键词 > 正文关键词 > 可选模型判断（按钮触发），
  预填"板块/资料类别/依据用途"，参考类永不建议为机制依据
- 三板块分类：产品知识（配方/工艺）· 行业知识（法规/摘要/行情/基准）· 企业内部知识（设备/派生基线/异常处理记录/通用制度）

### 2.2 文档切分策略

- 参数：size=900 字符、overlap=150、步长 750，单位为已确认正文 Unicode 字符偏移（end exclusive）
- 非表格文档：先按章节标题启发式分节（`source_sections`，显式箭头/通用条款/共用对比章节分类），
  **节内**切块不跨节；每块记录 offset/页码区间/章节/适用性（product/general/cross_product）
- CSV：一行逻辑记录=一个 chunk（保留原始行文本，不展平）；表头只入 metadata
- 共用对比章节（公用工程/设备利用率）按 general 条款参与机制证据（claim_boundary 声明不证明本期发生）

### 2.3 向量化方案

- 编码器：本地 **BGE-M3 dense-CLS**（transformers AutoModel，`local_files_only=True`、fp32/CPU、L2 归一化）
- 维度 1024（构建时记录进 manifest）；max_length=1024 且超长**不截断直接报错**
- 存储：每个发布一代一个 `managed/knowledge_releases/<release_id>/index.sqlite`，向量 JSON 存 chunks.vector 列
- 复用：仅"同模型指纹+同 chunk_id+同正文 sha256"才从 pinned 基础发布复制向量
- **模型指纹 = 权重目录全文件哈希 + torch/transformers 版本 + 运行配置**；环境变化→指纹不匹配→
  fail-closed（拒绝冒充混合检索成功），须重新发布索引

### 2.4 检索策略（四路混合 + 受控重排）

- 授权先行：每次检索重新判定 scope（主体范围∩文档范围∩发布代际∩撤销表），候选收窄发生在一切召回之前
- 四路召回（同一授权 chunk 集合）：
  1. **BM25**：中文重叠二元词+ASCII 整词（k1=1.5、b=0.75）
  2. **向量**：查询 BGE-M3 编码→暴力精确余弦（当前语料规模无需 ANN）
  3. **词项证据二部图**：词→片段，一跳 2.0/二跳衰减（明确标注词面共现非因果）
  4. **领域知识图谱**：产品/药材/工序实体别名识别 + 关系投票
     （product_contains_material / material_undergoes_process / process_uses_equipment /
     process_has_controlled_metric / process_precedes_process，仅取显式文本箭头）
- **RRF 融合**：k=60 四路等权，只按名次叠加
- **受控重排**：0.55×实体覆盖 + 0.25×关系支撑 + 0.12×短语命中 + 0.08×RRF（无领域实体命中时跳过）
- 结果每条带来源标注：文件名/页码/章节/offset/版本/生效日期/发布代际 + 分路分数 + 图谱依据原文引用
- **fail-closed**：require_hybrid 时向量路不可用→整次检索返回 unavailable（不静默降级冒充成功）

## 3. Prompt 设计文档

### 3.1 散文合同 bound-numeric-prose/1

- 服务器为每次生成构建**逐要素数值授权合同**：statement 池（primary_fact/observed_reason/focus/
  observed_labor/market_reference/document_quote/industry_reference）+ required 标注 + 边界句
- **结构区契约（归因模式）**：全部数值句标记 `presentation='structure'` 由程序渲染——
  模型只写十五字以上无数字的限定性机制解释、可选完整知识引用与建议；数字只允许出现在逐字复述的授权句内
- 十条规则：数字授权边界、逐字复述、上下文叙事版本、知识引用门控、evidence_ids 去重并集、
  负贡献保留、建议纪律（凭证类别逐字使用白名单、不声称缺失凭证已取得、不编号）、证据缺口措辞、次序、软字数
- few-shot：合成教学样例（三要素完整输入/输出对），明示"示例非新数字权限"
- 修正轮：校验失败→把 validation_diagnostics 逐条回传（rule_id/field/offending/expected）→
  换修正模型（correction_registry_id）修订一次→再失败降级确定性文本（status=model_rejected）

### 3.2 多模型协作

- 主模型初稿（当前 glm-4.5-air，timeout 120s）+ 修正模型（deepseek-flash）；
  硬预算 min(255, 2×timeout+15) 秒，worker 子进程可杀；输出上限 5000 token
- 实测：归因与对标均为"初稿被拒→修正轮 0 诊断通过"（used_llm=True, model_validated）

### 3.3 防编造三层校验

1. 证据 ID 必须存在且唯一（EVIDENCE_EXISTS/UNIQUE/ELEMENT）
2. 数字锁定：数值只能出现在获准完整句内（BOUND_NUMERIC_OUTSIDE_STATEMENT/NO_NUMERIC_IN_PROSE），
   不允许换指标/期间/方向/单位
3. 引用绑定：参考类 ID 只能绑定实际采用的完整参考句（REFERENCE_SENTENCE_ONLY/EVIDENCE_KIND）；
   凭证名白名单（RECORD_NAME_SCOPE/NO_INVENTED_AVAILABILITY）；结论须假设化（UNCERTAINTY_REQUIRED）；
   人工工时桥接方向（LABOR_OFFSET）；跨厂方向守卫（对标特有）

## 4. 报告模板解析逻辑

- 模板：`report/registry.py` 读取 Word 模板（`COST_DATA_DIR/月度成本分析报告模板.docx`），
  5 章节：①封面与基本信息 ②总成本概览 ③成本要素明细分析 ④重点产品专项分析 ⑤总结与建议
- 占位符识别：`{{产品名称}}/{{本月材料成本}}/{{环比变动率}}` 等动态占位符由数据层填充；
  章节标题固定识别，不依赖文件名/正则猜测
- 数据填充：`report/datafill.py` 从已授权成本表/归因/对标结果装配；数字由程序渲染，
  模型只生成"解释与建议"文本（同上散文合同）
- 导出：`report/export.py` PDF（reportlab，可嵌入中文 TrueType，缺字码位校验）+ Word（python-docx）；
  容器构建安装 Noto Sans SC（固定提交+字节数/SHA256 校验）

## 6. 部署与一键启动

- 本地：`start.bat`（自动选 Python→launch_system→API 8000+UI 8501+worker；`--no-worker`/`--with-mock` 可选）
- 容器：`docker compose up`（Dockerfile 固定 OIDC 预检、字体安装、UID 10001、只读数据卷；`
  deploy/container_smoke.py` 冒烟校验）；requirements.txt + Windows 锁文件（84 依赖+SHA256）
- 模型：BGE-M3 本地目录（`BGE_M3_PATH`）；外部模型经模型配置页保存凭据（.local，不进源码包）
- CI：`.github/workflows/ci.yml` 于 Ubuntu 24.04 运行公开测试白名单（离线、空数据目录、禁遥测）
